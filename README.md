# NETWORK-DIAGRAM-USING-CISCO-PACKET-TRACER

## Project by:
**Bualan Group**

## Description
This project is a network diagram created using Cisco Packet Tracer.
It shows how different devices like Router, Switch, and PC are connected
to form a simple Local Area Network (LAN).

## Devices Used
- 1x Router
- 1x Switch
- 4x PC / End Devices
- Straight-through and Copper Cables

## Network Topology
- Star Topology
- All PCs are connected to the Switch
- Switch is connected to the Router
- Router is used as the gateway for the network

## IP Addressing
- Network: 192.168.1.0 /24
- Router: 192.168.1.1
- PC0: 192.168.1.2
- PC1: 192.168.1.3
- PC2: 192.168.1.4
- PC3: 192.168.1.5

## How to Open
1. Download the .pkt file in this repository
2. Open Cisco Packet Tracer
3. Open the file
4. Click the PC and use Command Prompt to test connection
